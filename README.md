# ContestHub



🚀  Project Overview
ContestHub is a platform where creators can create and manage contests easily with full control over rules, deadlines, and submissions
Users can participate in contests, showcase their skills, and win exciting prizes
Admins can manage the entire platform, monitor activities, and control user roles and permissions
It is designed to make online competitions simple, fair, secure, and well-organized for everyone involved.


ContestHub allows:

- Creators to create and manage contests

- Users to participate and win prizes

 - Admins to control the platform and roles

 - It is designed to make online competitions simple, fair, and organized.

🛠️ Technologies Used

- HTML / CSS / JavaScript

- React / JavaScipt /Tailwind CSS/

- Node.js / Express/cors

- MongoDB / Firebase 

- Authentication System (JWT / Firebase Auth)

⭐ Core Features

🔐  Role-based system (Admin, Creator, User)

🏆  Create and participate in contests

✔️  Admin approves or rejects contests

🔁  Creator can update or delete contests

🎁  Prize and winner declaration system

👤  Admin can change user roles

📊   Dashboard for each role
